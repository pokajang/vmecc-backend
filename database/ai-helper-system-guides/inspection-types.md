# Inspection Types Available in VMECC

## Purpose

Identify the eight built-in inspection types shown in **Inspection** and choose the correct form for the work.

## Before you begin

Open **Inspection**. The options shown to you still depend on your access and the inspection types enabled for your work.

## Steps

1. Select **Conduct Inspection** and review the available type cards.
2. Select **Emergency Response Auxiliary Equipment** for auxiliary equipment inventory and condition checks.
3. Select **Fire Extinguisher** for location, certification, physical, signage, box, and operating checks.
4. Select **Fire Truck Daily Readiness** for the truck-first daily readiness roster, one-off checks, prepared rows, and required readings.
5. Select **High Angle Rescue Equipment** for workbook-backed rescue-kit checks with fixed quantity, condition, and remarks.
6. Select **Hydraulic Rescue Tools** for physical, mechanical, leakage, function, and defect checks.
7. Select **SCBA** for back plate, cylinder, and face mask checks.
8. Select **Health Safety Environment** to record an unsafe act or unsafe condition with a description and photo.
9. Select **General Inspection** for general condition, access, housekeeping, hazard, and compliance notes.

## What happens next

The selected type opens its own setup and checklist fields. Complete the visible fields, review the inspection, and submit the report.

## If something goes wrong

If a type is not shown, confirm that you opened **Conduct Inspection** and that the relevant inspection access is enabled for your account. Do not use a different type merely to bypass a missing option.

If the intended work does not match any displayed type, ask an authorized system owner to confirm which approved form should be used.

## Related tasks

Use **Inspection** records to find submitted reports and **Inspection Workflow Settings** to manage the review sequence when authorized.
