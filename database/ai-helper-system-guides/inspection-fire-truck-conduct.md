# Conducting a Fire Truck Daily Readiness Inspection

## Purpose

Complete and submit the Fire Truck Daily Readiness checklist for a selected truck and compartment.

## Before you begin

Open **Inspection** and confirm that the intended fire truck is available. Be ready to select a compartment, complete its prepared checklist rows, enter required readings, and record evidence for any issue.

## Steps

1. Go to **Inspection**, select **Conduct Inspection**, then select **Fire Truck Daily Readiness**.
2. Select the fire truck and confirm the truck reference shown by the system.
3. Select the relevant compartment to load its prepared daily readiness and one-off checklist items.
4. Complete every displayed daily status or reading. Enter the required odometer and fuel-level readings when the **FIRE TRUCK** group is selected.
5. Complete the displayed one-off condition checks. Add remarks and evidence for each reported issue where required.
6. Use **Save Draft** if the work is incomplete, or select **Continue to Review** after all required items are complete.
7. On the review page, confirm the truck, compartment checks, readings, findings, remarks, and evidence, then select **Submit Report**.

## What happens next

The submitted report appears in **Inspection** records and follows the configured review and approval sequence. When more compartments remain, use the available continuation action to proceed with the next compartment.

## If something goes wrong

If a truck or compartment is unavailable, return to setup and confirm the selected truck record. If review is blocked, complete the exact daily status, reading, one-off condition, remark, or evidence named by the validation message.

Keep a saved draft when the connection is interrupted and verify the restored truck and checklist content before continuing. Do not select a different inspection type merely to bypass a missing truck or checklist.

## Related tasks

Use **Inspection** records to view submitted reports. Ask an authorized inspection administrator to correct unavailable truck data or inspection access.
