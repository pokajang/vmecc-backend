# Conducting a Fire Extinguisher Inspection

## Purpose

Start and submit an onsite fire extinguisher inspection using the extinguisher's area or serial number.

## Before you begin

Confirm that the correct extinguisher records and locations already appear in **Inspection**. Have the extinguisher serial number ready if you will inspect one specific unit.

## Steps

1. Go to **Inspection**, select **Conduct Inspection**, then select **Fire Extinguisher**.
2. At **Choose Inspection Mode**, select **By Area** to inspect units at a location, or **Serial Number** to find one unit.
3. For **By Area**, choose the **Zone**, **Main Area**, and **Location**. For **Serial Number**, select **Search FE by Serial Number**, scan or enter the stored number, then open the matching unit.
4. Confirm the inspection date and inspector details, then complete every displayed extinguisher check and add remarks where required.
5. Add report evidence when needed, select **Save Draft** if work is incomplete, or select **Continue to Review** when all required checks are complete.
6. On the review page, confirm the selected extinguisher, location, checks, findings, and evidence, then select **Submit Report**.

## What happens next

The submitted report appears in **Inspection** records and follows the configured review and approval sequence. If more units remain in the selected area, use the displayed continuation action to proceed to the next location.

## If something goes wrong

If a serial number is not found, confirm that it matches a stored extinguisher record. If a required check blocks review, return to the named field and complete it. If the connection fails, keep the saved draft and retry after the connection returns.

Do not create a replacement asset merely to bypass a missing or incorrect serial number. Ask an authorized extinguisher manager to correct the asset record first.

## Related tasks

Use **All Extinguishers** to manage asset records and **Issues** to handle defects reported during inspection.
